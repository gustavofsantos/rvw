Report what stands between the workspace and a commit or push. Open comments
are pending or handed over and not yet decided, drafts included. Unjudged
comments were decided after a handoff and wait for a verdict. When neither
kind is left the output says clear.

The exit status is 0 either way: read the output. --lane looks at one lane and
never at an unlaned comment; without it, every lane is looked at.

Usage:
  rvw gate [flags]
  rvw gate [command]

Examples:
  rvw gate
  rvw gate --lane auth --format json
  rvw gate --all-lanes

Available Commands:
  override    record going ahead past an unclear gate, and why

Flags:
      --all-lanes       every lane, overriding --lane
      --format string   output shape: text, json (default: text) (default "text")
  -h, --help            help for gate
      --lane string     only this lane's comments (default: every lane)

Global Flags:
      --db string          database file (default: $XDG_DATA_HOME/rvw/rvw.db, else ~/.local/share/rvw/rvw.db)
      --workspace string   queue to act on: the git toplevel of this directory (default: $PWD)

Use "rvw gate [command] --help" for more information about a command.
