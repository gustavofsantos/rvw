Record that a commit or push went ahead although the gate was not clear. The
record keeps the action, the reason, and the open and unjudged ids at that
moment. It is refused when the gate is clear, since there is nothing to override.
Records are kept; nothing is deleted.

Usage:
  rvw gate override --action ACTION --reason TEXT [--lane LANE] [flags]

Examples:
  rvw gate override --action commit --reason "reviewer is out until Monday"
  rvw gate override --action push --lane auth --reason "hotfix" --author alice

Flags:
      --action string   commit or push (required)
      --author string   who overrides (default: $USER)
      --format string   output shape: text, json (default: text) (default "text")
  -h, --help            help for override
      --lane string     only this lane's comments (default: every lane)
      --reason string   why the action goes ahead (required)

Global Flags:
      --db string          database file (default: $XDG_DATA_HOME/rvw/rvw.db, else ~/.local/share/rvw/rvw.db)
      --workspace string   queue to act on: the git toplevel of this directory (default: $PWD)
