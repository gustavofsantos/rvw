Show one review comment as a fixed-width review line: its source, or the
diff it produced once done, and its note or resolution. A submitted review id
shows the whole review sheet. Nothing is dequeued.

Usage:
  rvw show ID [flags]

Examples:
  rvw show r3
  rvw show rv1
  rvw show r3 --format json

Flags:
      --format string   output shape: text, json, markdown (default: text) (default "text")
  -h, --help            help for show

Global Flags:
      --db string          database file (default: $XDG_DATA_HOME/rvw/rvw.db, else ~/.local/share/rvw/rvw.db)
      --workspace string   queue to act on: the git toplevel of this directory (default: $PWD)
