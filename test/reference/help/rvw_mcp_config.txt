Print the `claude mcp add` command, and the equivalent .mcp.json entry, that
register rvw as an MCP server in Claude Code. Nothing is changed; run the
command or paste the entry yourself.

By default Claude Code starts the server on stdio. With --http it connects to
a server you keep running with `rvw mcp serve --http ADDR`. --db, --workspace,
--lane and --author are carried into the server command.

Usage:
  rvw mcp config [flags]

Examples:
  rvw mcp config
  rvw mcp config --author claude --scope project
  rvw mcp config --http 127.0.0.1:7777
  rvw mcp config --format json          # only the .mcp.json entry

Flags:
      --author string   author of calls that name none (default: $USER)
      --format string   output shape: text, json (default: text) (default "text")
  -h, --help            help for config
      --http string     serve streamable HTTP on this loopback address (e.g. 127.0.0.1:7777) instead of stdio
      --lane string     pin calls that name no lane to this lane (default: every lane)
      --name string     server name in Claude Code (default "rvw")
      --scope string    claude mcp add scope: local, project, user (default "user")

Global Flags:
      --db string          database file (default: $XDG_DATA_HOME/rvw/rvw.db, else ~/.local/share/rvw/rvw.db)
      --workspace string   queue to act on: the git toplevel of this directory (default: $PWD)
