Serve the queue over the Model Context Protocol, for agents that prefer tool
calls to shell commands. Every tool is one rvw operation: add, submit, list,
list_reviews, count, pull, show_comment, show_review, resolve, edit and
workspaces. Each call names its workspace, so one server serves every project.

`rvw mcp config` prints how to register the server with Claude Code.

Usage:
  rvw mcp [flags]
  rvw mcp [command]

Available Commands:
  config      print how to add the MCP server to Claude Code
  serve       run the MCP server on stdio, or on a local HTTP address

Flags:
  -h, --help   help for mcp

Global Flags:
      --db string          database file (default: $XDG_DATA_HOME/rvw/rvw.db, else ~/.local/share/rvw/rvw.db)
      --workspace string   queue to act on: the git toplevel of this directory (default: $PWD)

Use "rvw mcp [command] --help" for more information about a command.
